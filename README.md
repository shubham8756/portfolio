## 💻 Local Development Setup

To run this portfolio application locally on your machine:

```bash
# 1. Clone the repository
git clone https://github.com/shubham8756/portfolio.git

# 2. Navigate into the project directory
cd portfolio

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

Open your browser at `http://localhost:3000` to view the application.

### 📦 Production Build

```bash
# Build the client app and server bundle
npm run build

# Start production server
npm run start
```
